PAGE 03ROUTER CONFIGURATION

3. Configure R1 Interfaces

Open R1 → CLI. If the initial configuration dialog appears, type no.

enable
configure terminal

interface gigabitEthernet 0/1
ip address 192.168.1.1 255.255.255.0
no shutdown
exit

interface gigabitEthernet 0/2
ip address 192.168.2.1 255.255.255.0
no shutdown
exit

interface gigabitEthernet 0/0
ip address 192.168.3.1 255.255.255.0
no shutdown
exit

end
copy running-config startup-config

Verify

show ip interface brief

G0/1 should be 192.168.1.1, G0/2 should be 192.168.2.1, and G0/0 should be 192.168.3.1. The status and protocol should be up/up.

PAGE 06DEDICATED DHCP

6. DHCP Method 1 — Dedicated DHCP Server

Concept: The separate DHCP SERVER at 192.168.2.254 provides DHCP service. For the initial dedicated-server activity, configure and test its local Network 2 clients. Remote networks require DHCP relay, covered in Method 3.

6.1 Enable DHCP

Open DHCP SERVER → Services → DHCP. Set DHCP: ON.

6.2 Create the Network 2 pool

Pool Name:        NETWORK2
Default Gateway:  192.168.2.1
DNS Server:       192.168.1.254
Start IP Address: 192.168.2.10
Subnet Mask:      255.255.255.0
Maximum Users:    100

Click Add.

6.3 Make PC2 and PC3 dynamic

Open PC2 → Desktop → IP Configuration → DHCP. Repeat for PC3.

6.4 Verify

ipconfig
ping 192.168.2.1
ping 192.168.2.254
ping 192.168.1.254
ping 192.168.3.254
PAGE 07ROUTER DHCP

7. DHCP Method 2 — Router as DHCP Server

Separate activity: Do not leave both the router DHCP service and the dedicated DHCP service actively assigning addresses for the same clients while testing this method.

7.1 Turn off dedicated DHCP

Open DHCP SERVER → Services → DHCP → OFF.

7.2 Configure R1 DHCP

Open R1 → CLI. For Network 1, addresses 192.168.1.1–192.168.1.10 are reserved, and 192.168.1.254 is reserved for the DNS Server. Therefore, the first available DHCP address is 192.168.1.11.

7.2.1 Reserved IP addresses

ip dhcp excluded-address 192.168.1.1 192.168.1.10
ip dhcp excluded-address 192.168.1.254

Confirmation: show running-config should display these excluded-address commands. show ip dhcp binding confirms the addresses actually leased to PCs.

Open R1 → CLI and continue with the DHCP pool:

enable
configure terminal

ip dhcp pool NETWORK1
network 192.168.1.0 255.255.255.0
default-router 192.168.1.1
dns-server 192.168.1.254
exit

ip dhcp pool NETWORK2
network 192.168.2.0 255.255.255.0
default-router 192.168.2.1
dns-server 192.168.1.254
exit

ip dhcp pool NETWORK3
network 192.168.3.0 255.255.255.0
default-router 192.168.3.1
dns-server 192.168.1.254
exit

end
copy running-config startup-config

7.3 Make every PC dynamic

For PC0 through PC5: Desktop → IP Configuration → DHCP.

7.4 Verify

show ip dhcp binding
show ip dhcp pool

Network 1 PCs should receive 192.168.1.x, Network 2 PCs should receive 192.168.2.x, and Network 3 PCs should receive 192.168.3.x.

PAGE 08DHCP RELAY

8. DHCP Method 3 — DHCP Server Relay

Why relay? DHCP client requests begin as broadcasts. Routers do not normally forward these broadcasts. ip helper-address tells R1 to forward DHCP requests to the dedicated DHCP server at 192.168.2.254.

8.1 Disable router DHCP pools

On R1:

enable
configure terminal
no ip dhcp pool NETWORK1
no ip dhcp pool NETWORK2
no ip dhcp pool NETWORK3

8.2 Turn ON the dedicated DHCP server

Open DHCP SERVER → Services → DHCP → ON.

8.3 Create all three DHCP pools on the dedicated server

Network 1

Pool Name:        NETWORK1
Default Gateway:  192.168.1.1
DNS Server:       192.168.1.254
Start IP Address: 192.168.1.10
Subnet Mask:      255.255.255.0
Maximum Users:    100

Click Add.

Network 2

Pool Name:        NETWORK2
Default Gateway:  192.168.2.1
DNS Server:       192.168.1.254
Start IP Address: 192.168.2.10
Subnet Mask:      255.255.255.0
Maximum Users:    100

Click Add.

Network 3

Pool Name:        NETWORK3
Default Gateway:  192.168.3.1
DNS Server:       192.168.1.254
Start IP Address: 192.168.3.10
Subnet Mask:      255.255.255.0
Maximum Users:    100

Click Add.

8.4 Add relay to Network 1

Network 1 enters R1 through G0/1:

interface gigabitEthernet 0/1
ip helper-address 192.168.2.254
exit

8.5 Add relay to Network 3

Network 3 enters R1 through G0/0:

interface gigabitEthernet 0/0
ip helper-address 192.168.2.254
exit
Do not add the helper to G0/2. G0/2 is Network 2, where the DHCP server already resides.

8.6 Save

end
copy running-config startup-config

8.7 Set all PCs to DHCP

For every PC: Desktop → IP Configuration → DHCP.

PAGE 09DNS

9. Configure DNS

The DNS SERVER is 192.168.1.254.

9.1 Enable DNS

Open DNS SERVER → Services → DNS and set DNS: ON.

9.2 Create the DNS record

Name:    www.dns.com
Address: 192.168.3.254

Click Add.

Correct mapping: www.dns.com → 192.168.3.254. The DNS server only translates the name; the HTTP server hosts the website.

PAGE 13TROUBLESHOOTING

13. Troubleshooting

PC gets 169.254.x.xCheck DHCP service, cable, switch connection, pool, and relay configuration. Renew by switching the PC to Static and back to DHCP.
PC gets wrong networkCheck which switch and router interface the PC is connected to. Confirm the DHCP pool network.
Can't reach another networkCheck R1 interfaces with show ip interface brief and verify gateways.
DNS name failsCheck that DNS is ON, the record is exactly www.dns.com, and the PC received DNS server 192.168.1.254.
IP works but website doesn'tTry http://192.168.3.254. If that fails, check HTTP SERVER → Services → HTTP → ON.
Relay doesn't workConfirm ip helper-address 192.168.2.254 is on G0/1 and G0/0, not G0/2.

Three DHCP methods

  1. Dedicated DHCP Server — DHCP service runs on the separate DHCP SERVER.
  2. Router as DHCP Server — R1 uses DHCP pools to assign addresses.
  3. DHCP Server Relay — R1 forwards remote DHCP requests using ip helper-address 192.168.2.254.
